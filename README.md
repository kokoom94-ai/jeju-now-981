# JEJU BEFORE — public beta deployment

This is an isolated deployment branch for the standalone JEJU BEFORE app delivered in the current conversation. The repository's main branch and existing 9.81 live service are not modified.

Target: https://jeju-before-walk.netlify.app

The app remains explicitly labelled as a schematic spatial draft, not a surveyed street model or a verified Naver places inventory. It contains 32 initial places, third-person walking, map view, popups, itinerary and local browser storage.

The exact delivered standalone HTML is Brotli-compressed into four base64 source parts under `.deployment/`. The publisher verifies both compressed and uncompressed SHA-256 checksums before deployment. The short-lived Netlify capability is encrypted to a one-time RSA public key generated by the current runner. Plaintext credentials and private keys are never committed to Git.

The workflow publishes only the standalone HTML and public status/security-header files to a new, dedicated Netlify site, then runs desktop/mobile HTTPS browser checks. Machine-readable publication and browser results are written under `deploy/`.

This branch is not intended to be merged into main. Subsequent releases should use a normal protected deployment secret or a new one-time session; encrypted past sessions cannot be reused by a new runner.
