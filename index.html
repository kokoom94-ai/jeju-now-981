나의 캐릭터로 미리 둘러보기

W A S D 또는 방향키로 이동합니다. 지도를 드래그하면 회전하고, 휠로 확대합니다. Shift를 누르면 더 빨리 움직입니다. 장소를 선택한 뒤 ‘여기로 걷기’를 누르면 가상 경로를 따라 이동합니다.

사전 체험용 베타 · 실제 내비게이션이 아닙니다.

포함 범위

일도동·이도동·건입동·삼도동·용담동과 제주국제공항 전체를 둘러싼 넓은 사각형 범위입니다. 동별 버튼은 대표점 이동이며, 실제 행정경계의 완전 포함을 검증한 결과가 아닙니다. 공항 활주로·계류장은 보행 경로에서 제외합니다.

장소 정보와 네이버 지도

기본 장소는 수동으로 구성한 32개 초안이며 전수 목록이 아닙니다. 대부분의 좌표와 주차장 명칭·출입구는 검증 전입니다. ‘네이버 지도에서 확인’은 네이버 검색 결과로 이동하는 링크이며 네이버 API 연동 완료를 뜻하지 않습니다. 영업시간·요금·평점·잔여 객실·주차 가능 면수는 임의로 만들지 않습니다.

내 장소와 나의 여정

추가한 장소, 캐릭터와 저장 목록은 이 브라우저에만 저장됩니다. 다른 방문자에게 자동 공개되지 않습니다. 내 장소를 JSON으로 내보내고 검토한 뒤 서버의 data/places.custom.json에 반영해 재배포할 수 있습니다. 공유되는 공개 CMS나 회원 로그인은 없습니다.

실제 지도 원본 불러오기

공개 OSM 원본 서버에서 이 범위의 도로·건물을 요청합니다. 네트워크 연결이 필요하며 1~3분 걸릴 수 있습니다. 실패하면 현재 초안을 유지합니다. 네이버 원본이나 실측 외벽 모델이 아닙니다.

공간 데이터 상태

실제 지도 원본을 연결해도 건물 높이·외벽·계단·경사·보도·횡단보도·실내는 별도 검증이 필요합니다. 경로는 원본의 보행 관련 태그를 참고하는 가상 경로이며 접근성·안전을 보장하지 않습니다.

개인정보와 권리

GPS, 카메라, 계정 가입을 요구하지 않습니다. 서버 검색 사용 시 검색어가 네이버에 전송될 수 있습니다. GTA의 로고·지도·음악·캐릭터는 사용하지 않은 독자적인 오픈월드 여행 시안입니다.
