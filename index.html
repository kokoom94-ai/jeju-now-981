공식 원본 연결
표시된 프록시는 배포 예정 주소입니다. 서버 배포 후 사용하세요. 키는 서버 환경변수에만 직접 설정하며 이 입력창으로 보내지 않습니다. SDK 초기 요청만 중계하고 건물·지형 원본은 공식 SDK가 요청합니다.
계정 비밀번호나 서버 비밀키는 입력하지 마세요. 앱은 키를 저장·내보내기하지 않습니다. 브라우저 SDK 요청에는 보이므로 제공기관의 도메인 제한을 적용해야 합니다.
